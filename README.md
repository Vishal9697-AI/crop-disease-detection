🌱 Crop Disease Detection using Deep Learning (CNN)

📌 Overview
This project is a Deep Learning-based Crop Disease Detection system that classifies plant leaf images into different disease categories using a Convolutional Neural Network (CNN).

The goal is to help farmers and researchers quickly identify crop diseases and take early action to improve crop yield.

🧠 Problem Statement
Manual identification of crop diseases is time-consuming and requires expertise.
This project automates the process using image classification techniques to detect diseases from leaf images.

🚀 Features

🌿 Detects crop leaf diseases from images
🧠 Built using CNN (Convolutional Neural Network)
📊 Shows model accuracy and performance
🖼️ Predicts disease class from input image
⚡ Fast and automated prediction system

🛠️ Tech Stack
Python 🐍
TensorFlow / Keras 🤖
NumPy & Pandas 📊

⚙️ How It Works

--> Collect plant leaf image dataset
--> Preprocess images (resize, normalize)
--> Train CNN model on labeled dataset
--> Save trained model
--> Input new image → model predicts disease class

🧪 Model Architecture
--> Convolutional Layers (feature extraction)
--> Max Pooling Layers (dimensionality reduction)
--> Flatten Layer
--> Dense Fully Connected Layers
--> Softmax Output Layer (multi-class classification)
