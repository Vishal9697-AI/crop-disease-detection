Crop Disease Detection Project 🌱

## Description
CNN model to detect crop leaf diseases from images.

## Tech Stack
Python, TensorFlow, Keras

This Project Is About Crop Leaf Disease. It Get The Plant Image And Predict Disease Name From The Picture Of The Leaf.
In This I Used CNN Because CNN Is The Best Neuron Network For Working With Image.

My Model Is Not Very Accurate Right Now. I Am Searching For More Data. 

For Now It's Only Trained For Gujarat State's Most Popular Crops Like Wheat, Cotton, Rice But In Future I Will
Add On More Spacific Data And Fill With Images Like Clicks On Cheap Mobiles, Android Images, Also Image That Includes Dusty Pic Of Crop,
and Many More Things To Add On. 

It Can Be A Good For Farmers Like If They Want To Check Like Their Crop Has Any Disease Or Not Than Absolutely They Just Have
To Click Picture Of That And Than This Model Shows Is Crop Has Disease or Not.
